# Payment Reconciliation Lab source

Local synthetic payments dashboard with Node.js, SQLite, exception triage, settlement previews and signed demo webhooks. Requires Node.js 22 or newer. From this directory, run `npm start` and open <http://127.0.0.1:4321>. Run `npm test` for the app's automated suite. Companion QA suite: https://github.com/parshvasanghavi2005/qa-payment-reconciliation.

The app uses synthetic records only and does not process real payments. Its generated SQLite database and secrets are not included in this portfolio copy.
